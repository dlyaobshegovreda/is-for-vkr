# Информационная система автосервиса (СТО)

Веб-приложение для автоматизации работы автосервиса: учёт клиентов и
автомобилей, оформление заказ-нарядов, складской учёт запчастей,
запись на приём и отчётность.

## Стек
- Python + Django 6
- БД: SQLite (разработка) / PostgreSQL (продакшен)
- Django Templates + Bootstrap 5
- ReportLab (PDF), openpyxl (Excel), Chart.js (графики)

> PDF генерируется через ReportLab — чистый Python, **без системных библиотек**
> (работает на Windows, Linux и macOS сразу после `pip install`). Кириллица
> обеспечивается встроенным шрифтом DejaVu Sans (`workshop/fonts/`).

## Возможности (реализовано)
- Аутентификация и разграничение прав по ролям: администратор,
  мастер-приёмщик, механик.
- Справочники (CRUD, поиск, пагинация): клиенты, автомобили, услуги,
  категории услуг, поставщики, запчасти.
- Карточка клиента с автомобилями и историей обслуживания.
- **Заказ-наряды** — ядро системы:
  - оформление с привязкой к клиенту и автомобилю;
  - позиции работ (с механиком-исполнителем) и запчастей;
  - автоматический расчёт стоимости (работы + запчасти);
  - списание запчастей со склада в транзакции и контроль остатков;
  - жизненный цикл по статусам с проверкой допустимых переходов;
  - отметка оплаты; возврат запчастей на склад при удалении заказа.
- **Запись на приём**:
  - список с поиском и фильтром по статусу, подсветка просроченных записей;
  - контроль занятости временного слота (нельзя записать два авто в один интервал);
  - статусы записи (запланирована/подтверждена/завершена/отменена);
  - создание заказ-наряда прямо из записи (интеграция модулей).
- **Отчёты и аналитика** (для администратора):
  - сводка за период: выручка, число заказов, средний чек, сумма проданных запчастей;
  - выручка по месяцам, загрузка механиков, востребованные услуги, движение запчастей;
  - фильтр по датам; визуализация на графиках (Chart.js).
- **Дашборд** с диаграммами: распределение заказ-нарядов по статусам и выручка по месяцам.
- **Печатные формы (PDF)**: заказ-наряд и акт выполненных работ (ReportLab, с реквизитами автосервиса и кириллицей).
- **Выгрузка отчётов в Excel** (openpyxl): сводка, все заказ-наряды за период, выручка по месяцам, топ клиентов, механики, услуги, запчасти — на отдельных листах.
- Расширенная аналитика: выручка и её структура (работы/запчасти), средний чек, нормо-часы, средний срок ремонта, клиенты (всего/новые), топ клиентов, низкие остатки склада и полный список заказ-нарядов за период.

## Запуск
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo            # реалистичные демо-данные + админ admin / admin12345
# или заново:  python manage.py seed_demo --reset
python manage.py runserver
```
- Приложение: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/

## Структура
- `config/` — настройки проекта
- `users/` — пользователи, роли, контроль доступа (`access.py`)
- `workshop/` — предметная область (модели, формы, представления, шаблоны)
  - `management/commands/seed_demo.py` — наполнение демо-данными
